# Mi presentación

En este proyecto, tarea de la clase 3 de esta diplomatura, creé un repositorio de nombre *mi-presentacion*. 

Inicialmente, me agregué todo lo solicitado en la consigna:
* Un ``index.html`` con sus respectivos boilerplate y body, semánticamente indexado.
* Un ``style.css`` linkeada a ``index.html`` con estilos que nos tocó investigar.
* Un ``README.md`` dónde se explique de qué se trata este proyecto, que es dónde estoy escriiendo ahora.

Luego... me tomé la libertad de investigar y agregar estilos que ya conocía pero con necesidad de refrescarlos.
Entre otras cosas, utilicé ``display: flex;`` y ``:hover``.

Tuve que rehacer ``style.css`` para entenderlo de manera más clara. Al archivo anterior lo nombré ``old-style.css`` y es obsoleto.
